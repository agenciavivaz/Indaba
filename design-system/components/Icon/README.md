# Icon

Ícones de traço de 2px, pontas arredondadas e grade de 24px, que herdam a cor do texto (`currentColor`).

**O que você fornece:** `name`, `size` (14 em rótulos, 16 em botões e linhas, 20 em cabeçalhos, 24 em estados vazios), `strokeWidth` e `label` (só quando o ícone carrega sentido sozinho).

- Em produção use **Lucide** (`lucide-react`, o padrão do shadcn/ui). Este conjunto foi desenhado no mesmo traço só para os previews. O mapeamento: `email` Mail, `linkedin` Linkedin, `phone` Phone, `whatsapp` MessageCircle, `ads` Megaphone, `search` Search, `sparkle` Sparkles, `eye` Eye, `lock` Lock, `unlock` LockOpen, `route` Route, `hand` Hand, `raise` ArrowUp, `send` Send, `database` Database, `link` Link, `form` FileText, `map` Map, `list` List.
- `sparkle` é reservado à IA.
- Sem logos coloridos de terceiros e sem emoji.
