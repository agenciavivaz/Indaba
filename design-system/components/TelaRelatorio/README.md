# Tela: Relatório, aba Resumo

A home do gestor e do board, no Modo Relatório (claro por padrão; troque o tema da página para ver em Papel). Sóbrio, nível Linear e Vercel: sem relevo, sem HUD, sem linguagem de jogo nos títulos.

- O alerta de dependência de origem aparece no topo quando uma origem passa de 80% dos pontos.
- Os números são separados em **Resultado** e **Execução**, para que execução subindo sem resultado aponte para a oferta e não para o produto.
- "Programa hoje" mostra a distribuição por temperatura e os maiores scores. As tendências comparam com o período anterior.
- A leitura do período é da IA e vem marcada como rascunho em `jacaranda`. Os números nunca vêm da IA.
- Execução por BDR fica na aba Execução, só para o gestor, e nunca como ranking.
