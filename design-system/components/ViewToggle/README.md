# ViewToggle

Alternância entre Mapa e Lista (no Território) ou Mapa e Tabela (no Comitê). É um grupo de rádio com setas do teclado.

**O que você fornece:** `value` e `onChange` (ou `defaultValue`), `options` (`{ id, label, icon }`) e `label`.

- O mapa e a lista mostram os mesmos dados. A lista é a tabela densa do kanban atual, com os mesmos contadores.
- Lembre a escolha por pessoa (armazenamento local), nunca por workspace.
