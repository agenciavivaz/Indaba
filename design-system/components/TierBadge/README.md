# TierBadge

O tier da conta, diferenciado por peso: T1 cheio em `ink`, T2 contornado, T3 só texto.

**O que você fornece:** `tier` (1, 2 ou 3) e `showMode` para mostrar o tratamento (1:1, 1:poucos, 1:muitos).

- O T3 deixou de ser tracejado: no sistema, tracejado significa névoa ou "ainda não é real".
- O tier nunca usa cor de calor ou de objetivo. Tamanho no território e peso no selo bastam.
