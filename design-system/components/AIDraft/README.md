# AIDraft

Tudo que a IA gera nasce aqui como rascunho: contorno tracejado `jacaranda`, fundo `jacaranda-soft` e o chip "Rascunho da IA". Quando um humano aprova ou edita, o roxo sai.

**O que você fornece:** `body`, `subject` (só e-mail), `status` (`pending`, `loading`, `accepted`, `edited` ou `discarded`), `agent` (nome do agente), `editable`, `onCopy`, `onEdit`, `onRegenerate` e `footnote` (de onde a IA tirou o contexto).

- O roxo é exclusivo da IA. Não use `jacaranda` para destaque, categoria ou marca.
- Copiar é a ação principal (tecla C), porque o BDR envia pelo próprio canal.
- O texto do rascunho segue as regras do Redator: sem rótulos internos no assunto, cita o sinal real, uma pergunta por mensagem, sem "espero que esteja bem".
- Carregando, mostre linhas de esqueleto com "Escrevendo rascunho" para leitor de tela. Nada de animação de digitação.
