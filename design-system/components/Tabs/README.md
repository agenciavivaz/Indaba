# Tabs

Abas de seção. Setas esquerda e direita trocam de aba.

**O que você fornece:** `items` (`{ id, label, count }`), `value` e `onChange` (ou `defaultValue`) e `label` para o tablist.

- No Mapa da conta: Comitê, Sinais, Dossiê e assets, Replay, Negócio. No Relatório: Resumo, Sinais, Jornada das contas, Onde agir, Execução, Visão por conta.
- A contagem é neutra e tabular. Não use a contagem como meta.
