# Select

Select nativo (teclado e leitor de tela de graça) com o estilo do sistema.

**O que você fornece:** `label`, `options` (`{ value, label, disabled }`), `value` ou `defaultValue`, `onChange`, `hint`, `error`, `size` (`sm` em barras de filtro) e `inline` (rótulo ao lado, para filtros).

- Use em filtros e formulários do Modo Relatório e do Programa. Para trocar de visualização, use `ViewToggle`; para abas, `Tabs`.
- "A definir" é uma opção válida para trilha, mas trava o gate e o erro diz isso.
