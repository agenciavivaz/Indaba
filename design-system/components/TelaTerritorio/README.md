# Tela: Território

O mapa do programa. O trabalho da tela é mostrar onde o programa está forte e onde está fraco.

- Colunas por fase (Alvo, Aquecendo, Engajada, Em cadência, Conversa, Reunião), com o mesmo relevo do Mapa da conta ao fundo. Cada conta é um `TerritoryNode`: tamanho pelo tier, anel pelo cerco, miolo pela temperatura, cadeado pelo gate.
- Sinais das últimas 24h pulsam uma vez ao abrir a tela. Nada pisca em loop.
- A alternância Mapa | Lista troca para a tabela densa com os contadores do kanban atual.
- Os filtros "Sem sinal há 21+ dias" e "Engajada sem ofensiva" são os atalhos de "Onde agir".
