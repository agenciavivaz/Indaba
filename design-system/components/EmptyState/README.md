# EmptyState

O que aparece quando falta algo. Vazio é convite: diz o que falta em uma frase e oferece a ação que resolve.

**O que você fornece:** `icon`, `title`, `body`, `action` (um `Button` primário), `secondaryAction` e `compact`.

- O título descreve o estado na linguagem do mapa ("Comitê ainda em névoa"). O botão usa verbo e objeto ("Buscar comitê no Apollo").
- O ícone fica dentro de um círculo tracejado `nevoa`, pela mesma razão do mapa: ainda não é real.
- Sem ilustração, mascote ou humor.
