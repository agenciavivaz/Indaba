# Tela: Mapa da conta no mobile

O mesmo Mapa da conta em 390px. A ordem muda para servir a uma decisão: cabeçalho, HUD, objetivos, **Próxima jogada**, o mapa compacto e os últimos sinais.

- O mapa usa `compact`: assentos de 40px, rótulo da rota acima dos assentos, três por linha.
- Os alvos de toque têm pelo menos 44px nos botões de ação (`control-lg`), e os atalhos de teclado somem em telas de toque.
- A página não rola de lado. A tabela do comitê só aparece no desktop.
